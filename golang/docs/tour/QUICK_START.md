# Quick Start Guide

## Opening the Go Tour in Your Browser

1. **Navigate to the tour directory:**
   ```
   golang/docs/tour/
   ```

2. **Open the main page:**
   - Double-click `index.html` to open in your default browser
   - OR right-click `index.html` → "Open with" → Choose your preferred browser

3. **Start learning:**
   - Click on any section card to jump to that topic
   - Use the sidebar navigation to browse all pages
   - Use Previous/Next buttons at the bottom to progress through lessons

## Tour Structure

```
golang/docs/tour/
```

## Features

- **Interactive Navigation**: Click through topics with sidebar menu
- **Code Examples**: Go and C# side-by-side with syntax highlighting
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Progress Tracking**: Previous/Next buttons to move through lessons
- **Visual Sections**: Color-coded Go (blue) and C# (purple) sections

## Browser Compatibility

Works with all modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera

No internet connection or web server required - just open the HTML files directly!
