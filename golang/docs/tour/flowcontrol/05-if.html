Go Concept

Go's if statement is similar to C-style if statements, but:

  • No parentheses () around the condition
  • Braces {} are required (even for single statements)

The condition doesn't need parentheses, making it less cluttered. The braces are required to avoid ambiguity and common bugs.

Go Example

package main

import (
	"fmt"
	"math"
)

func sqrt(x float64) string {
	if x < 0 {
		return sqrt(-x) + "i"
	}
	return fmt.Sprint(math.Sqrt(x))
}

func main() {
	fmt.Println(sqrt(2), sqrt(-4))
}

C# Equivalent

C# if statements require parentheses around the condition:

  • Parentheses () are required around the condition
  • Braces {} are optional for single statements but recommended
  • Same boolean expressions and logic

The concepts are identical, only the syntax requirements differ.

C# Example

using System;

class Program
{
    static string Sqrt(double x)
    {
        if (x < 0)  // Parentheses required in C#
        {
            return Sqrt(-x) + "i";
        }
        return Math.Sqrt(x).ToString();
    }

    static void Main()
    {
        Console.WriteLine($"{Sqrt(2)} {Sqrt(-4)}");
    }
}

Key Differences

  • Parentheses: Go doesn't use parentheses around conditions; C# requires them
  • Braces: Go always requires braces; C# allows omitting them for single statements (not recommended)
  • Syntax Cleanliness: Go's syntax is slightly cleaner without parentheses; C# is more traditional C-style
  • Error Prevention: Go's mandatory braces prevent "dangling else" bugs; C#'s optional braces can lead to bugs
  • Use Case Alignment: Both provide conditional execution. The logic and use cases are identical. The only differences are:
  • Parentheses requirement (C# yes, Go no)
  • Brace requirement (Go always, C# optional but recommended)

This is purely syntactic � the functionality is the same. Many C# style guides recommend always using braces, bringing it closer to Go's enforced style.
